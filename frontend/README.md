# Frontend boekenwinkel

Deze frontend is gemaakt met HTML, CSS en gewone JavaScript. Er is geen framework nodig.

## Starten

1. Start MySQL.
2. Start `CatalogusApplication` in IntelliJ (poort 8081).
3. Start `ExamenAaYassineApplication` in IntelliJ (poort 8080).
4. Open `http://localhost:8080` in je browser.

De reserveringsservice toont de HTML-, CSS- en JavaScript-bestanden uit deze map. De frontend haalt boeken en voorraad op bij de catalogusservice op poort 8081 en gebruikt de reserveringsservice op poort 8080 voor profielen, reserveringen en reviews.

De gebruikerslogin en de bewaarde reserveringslijst zijn alleen bedoeld voor deze cursusdemo.
